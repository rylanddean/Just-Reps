## Principles for evaluating new features

1. **Does it lower the barrier to logging?** If not, it's probably V3.
2. **Can a first-time user ignore it completely?** New features must not clutter the home screen.
3. **Is the delight subtle?** No confetti, no fake coins, no casino mechanics.
4. **Does it reward consistency, not performance?** We celebrate showing up, not PRs.
