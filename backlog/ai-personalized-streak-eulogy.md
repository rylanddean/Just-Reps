# AI-Personalized Streak Eulogy

> It happened. It was specific. It was yours.

---

## Summary

A V2 enhancement to the completed Streak Eulogy. Instead of fixed copy tied to streak length, an on-device language model generates one line that reflects the actual pattern of *that specific streak* — derived from the `WorkoutEntry` timestamps and rep counts. The format is unchanged: streak number, one line, a "Start again" button. Only the line becomes personal.

**Prerequisite:** Streak Eulogy feature must be complete (it is).

---

## Why it fits the brand

The current eulogy is honest and quiet, but it's the same for everyone. "47 days. That's discipline." and "47 days. That's discipline." — two different people, two different stories, same words. FoundationModels lets the line reflect the actual texture of the streak — the days of the week, the time of day, the exercise mix — without becoming a report or a dashboard. One sentence. Still yours. Just truer.

On-device processing keeps the moment private. No streak data leaves the phone.

---

## How it's different from the V1 Eulogy

| | V1 (live) | V2 (this item) |
|---|---|---|
| Copy source | Hardcoded by streak length | Generated by FoundationModels |
| Specificity | "That's discipline." | "Mostly mornings. Not one Monday missed." |
| Data used | Streak length only | Entry timestamps, days of week, exercises |
| Device requirement | None | Apple Intelligence (iOS 18.1+) |
| Fallback | — | V1 hardcoded copy |

## Apple Intelligence technical approach

**Framework:** `FoundationModels` (iOS 18.1+)

**Generation trigger:** Same as V1 — first launch after a streak of ≥ 7 days breaks.

**Input to the model (injected as system context):**

```swift
struct EulogyContext: Codable {
    let streakLength: Int           // e.g. 47
    let exercises: [String]         // e.g. ["Push-ups", "Squats"]
    let mostCommonHour: Int         // e.g. 7 (7AM)
    let dayDistribution: [String]   // e.g. ["Mon": 47, "Tue": 44, "Sat": 31, ...]
    let startDate: String           // e.g. "March 4"
    let endDate: String             // e.g. "April 19"
}
```

**System prompt (strict, narrow):**

> You write one line of quiet, factual copy for a fitness streak that just ended. The line observes something specific and true about this particular streak — the days, the times, the habit. Never give advice. Never use exclamation points. Never say "great" or "amazing." Maximum 8 words. Output only the line, nothing else.

**Output schema:**

```swift
@Generable
struct EulogyLine {
    var line: String  // e.g. "Mostly mornings. You never missed a Monday."
}
```

**Fallback:** If Apple Intelligence is unavailable or the model fails, silently fall back to V1 hardcoded copy. The user never knows.

**Session lifecycle:** `LanguageModelSession` created, one exchange, session discarded. No conversation history retained.

## Design

The sheet is identical to V1. Only the copy line changes.

```
┌────────────────────────────────────┐
│                                    │
│  47 days.                          │
│  Mostly mornings. Never a Monday.  │
│                                    │
│         [ Start again ]            │
│                                    │
└────────────────────────────────────┘
```

Generated line character limit: 60 characters. If the model returns longer, trim at the last word boundary before 60 characters.

**No indicator that the line is AI-generated.** It's just the line. The personalisation is the feature, not the technology.

---

## Copy principles for the generated line

The model must be guided (and tested) to produce lines that match brand voice:
- **Factual, not motivational:** "You showed up on weekends too." not "You're incredible."
- **Specific, not generic:** "46 of 47 days before noon." not "You were very consistent."
- **Past tense only:** This streak is over. The line honours it, doesn't spin it forward.
- **Never shaming:** The streak broke — no line should imply that was bad.

**Example outputs (target range):**

- "Mostly mornings. Never a Monday missed."
- "Every weekday. Weekends when you could."
- "Push-ups every single day. Squats, almost."
- "46 days before noon. You're a morning person."
- "From March through April. Real time."

---

## Acceptance criteria

- [ ] `FoundationModels` session created on first launch after streak ≥ 7 breaks
- [ ] `EulogyContext` struct assembled from `WorkoutEntry` records for the broken streak period
- [ ] Generated line is ≤ 60 characters
- [ ] If Apple Intelligence unavailable: V1 hardcoded copy shown, no error surfaced
- [ ] If generation fails or times out (>3s): V1 fallback, no error surfaced
- [ ] No network calls — verified with proxy
- [ ] Sheet is visually identical to V1
- [ ] No "AI generated" indicator in the UI

---

## What this is NOT

- Not a summary or report — one line, not a paragraph
- Not advice for next time — eulogy only, no forward-looking copy
- Not stored anywhere — the generated line is discarded after the sheet is dismissed
- Not shown if Apple Intelligence requires onboarding — silently fall back
